# Baseline (2026-11-01)

The starting point for the [optimization plan](../plan.md), measured at
commit `8d2cd4b` with `bench/run.exe` (1 warm-up and 5 measured runs,
median). The raw rows are in [results.csv](../results.csv).

Host: Intel Core Ultra 5 125H (via WSL2), OCaml 5.4.1 without flambda.

## Where the time goes

`perf record` on `calls`, grouped by function:

| share | function | what it is |
|------:|----------|------------|
| 23% | `compare_val` | OCaml's generic comparison, called by the decoder's table searches |
| 9% | `List.find_map` | the decoder searching `Opcode` tables |
| 9% | `caml_hash` | hashing page numbers for the memory `Hashtbl` |
| 5% | `Decode.decode` | the decoder itself |
| 5% | `Hashtbl.find_opt` | the memory page lookup |
| 5% | `Memory.load` | reading memory |
| 4% | `caml_equal` | generic equality |
| 4% | `Decode.field` | extracting bit fields |
| 4% | `Cpu.execute` | the actual work |

So about **half the time is decoding**: the decoder finds opcodes by
searching lists with generic comparison, and this happens again every
time an instruction runs. Memory page lookups take another ~16%. Actually
executing instructions is under 10%.

This also explains the one surprise in the table: `calls/rvc` is twice as
fast as `calls`. Compressed instructions are expanded by a direct
`match` on their bits, which is much cheaper than the table search for
32-bit ones.

`fp` spends its time more evenly, with the exact-rounding code in `Fpu`
(`two_sum` and friends) on top of the same decoding cost, and allocates
4–5× more than the integer benchmarks.

Host CPU counters (`perf stat -e instructions`) are not available under
WSL2, so host instructions per guest instruction can't be measured on
this machine. At about 5 MIPS on a core boosting to about 4.5 GHz, it's
roughly 900 cycles per guest instruction.

## Consequences for the plan

The profile changes the order of the plan: the **decode cache (O4)
comes first**, because it removes the largest cost outright. Unboxed
registers (O2) and the software TLB (O3) follow.
